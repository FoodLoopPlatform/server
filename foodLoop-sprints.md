# **Parallel Work Strategy** 

One mistake many student teams make is waiting for another team to finish. Instead, work in parallel using agreed API contracts. 

**Team Primary Focus** Frontend 1 Consumer Marketplace + Cart Frontend 2 Business Portal + Admin Backend 1 Authentication + Orders + Users Backend 2 Products + Search + Inventory + Admin Mobile 1 Consumer App Mobile 2 Business App AI OCR → Classification → Pricing → Integration
